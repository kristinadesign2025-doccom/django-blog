# Django Blog

Учебный проект блога на Django с системой отзывов.

## Описание

Это веб-приложение блога, разработанное на Django. Проект включает:
- Главную страницу с списком постов
- Страницу "О блоге"
- Детальные страницы постов
- Систему отзывов с модерацией через админ-панель

## Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL_вашего_репозитория>
cd django-blog
```

### 2. Создание виртуального окружения

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Linux/Mac:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Применение миграций базы данных

```bash
python manage.py migrate
```

### 5. Создание суперпользователя (для доступа в админ-панель)

```bash
python manage.py createsuperuser
```

Следуйте инструкциям на экране для создания учетной записи администратора.

### 6. Запуск сервера разработки

```bash
python manage.py runserver
```

Сервер будет доступен по адресу: http://127.0.0.1:8000/

## Использование

### Доступ к админ-панели

1. Перейдите по адресу: http://127.0.0.1:8000/admin/
2. Войдите, используя учетные данные суперпользователя
3. Здесь вы можете управлять отзывами и одобрять их для публикации

### Основные страницы

- **Главная:** http://127.0.0.1:8000/
- **О блоге:** http://127.0.0.1:8000/about/
- **Отзывы:** http://127.0.0.1:8000/reviews/
- **Пост:** http://127.0.0.1:8000/post/1/ (где 1 - ID поста)

## Функциональность

### Система отзывов

- Пользователи могут оставлять отзывы через форму на странице `/reviews/`
- Отзывы требуют модерации администратором
- Только одобренные отзывы (с галочкой "Проверено") отображаются на сайте
- Администратор может управлять отзывами через админ-панель

### Шаблоны

Проект использует наследование шаблонов:
- `base.html` - базовый шаблон с общей структурой
- Остальные шаблоны наследуются от базового

## Разработка

```bash
python manage.py makemigrations
python manage.py migrate
```

